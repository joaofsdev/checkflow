# Glossário

| Termo | Definição |
|-------|-----------|
| **Check-in** | Registro da chegada do hóspede, que ocupa o quarto e altera seu estado para `Ocupado`. |
| **Check-out** | Registro da saída do hóspede, que libera o quarto e altera seu estado para `Limpeza Pendente`. |
| **Governança** | Setor responsável pela limpeza e arrumação dos quartos. Confirma a conclusão da limpeza. |
| **Estado do quarto** | Situação atual do quarto no ciclo operacional: `Livre`, `Ocupado` ou `Limpeza Pendente`. |
| **Livre** | Quarto limpo e disponível para receber uma nova ocupação. |
| **Ocupado** | Quarto com hóspede hospedado (check-in realizado, check-out pendente). |
| **Limpeza Pendente** | Quarto liberado após check-out, ainda não higienizado pela governança. |
| **Reserva / Estadia** | Vínculo entre um hóspede e um quarto para um período previsto. |
| **Extrato do quarto** | Somatório de diárias e consumos associados à estadia (N2/N3). |
| **Minibar** | Consumos avulsos do hóspede lançados na estadia (N2/N3). |
| **Precificação dinâmica** | Variação da diária conforme alta/baixa temporada (N2/N3). |
| **Alta/Baixa temporada** | Períodos com preços de diária diferenciados. |
